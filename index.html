02 — Register

Get approved

  1. Steam → View my profile → right-click → Copy Page URL. /id/ or /profiles/ both work.
  2. In Discord run /steam-request and paste that URL. Wait for an admin to Approve.
  3. Want a reserved paint? /livery-set — an admin has to approve that too. A reserve holds a pit slot.

Livery priority: local CVSCC members, then SSCLAC members, then everyone else.
