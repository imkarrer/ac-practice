Race weekend

End to end

Quali runs on factory paints so the download does not change while people are lapping. Numbers are baked when quali closes. The race server pins each Steam ID to that numbered skin.

  1. once Link Steam /intake — Steam + number → staff Approve
  2. driver Series signup /ac-practice signup — color dropdown
  3. driver Quali server Join. Factory skin only. Cuts discard that lap.
  4. server Hotlaps recorded Legal personal bests land on your Steam ID.
  5. admin Close quali /admin quali-close
  6. server Sort the grid Fastest first. No lap → back. Still on the list.
  7. server Bake numbers Door numbers on the race skins. Same number all season.
  8. driver Race server Pole is first pit. Skin is your numbered car, not quali paint.
  9. admin Points /admin results-import → results-finalize

After quali closes

How the grid is set

Assetto Corsa has no async quali API. Legal laps (no cuts) become a sorted list. That list is pit order on the race server. Live quali on race night is the other option — one server, AC sorts it — and is a poll question.

Quali

Factory paint

The skin you picked at signup. No door numbers yet, so the car zip does not have to change mid-session.

Cut a lap = that lap does not count. Miss the session entirely = last on the grid, still racing.

Race

Numbered cars

Same people, new skins. Pit order is the sorted grid, not who signed up first.

Discord

Commands people actually run

Who Command What it does
admin /admin init Create a series: name + car, optional first track.
admin /admin add-round Append a track. Then /admin round-open for the Discord channel.
once /intake Steam profile + race number 1–999. Number is unique. Staff approves.
practice /livery-set Reserve a practice car + color. Not used by the series.
driver /ac-practice signup Join the championship. Color optional. Number comes from `/intake`.
driver /ac-practice withdraw Leave before the grid is locked.
driver join the quali IP Hotlap. Legal PBs land on your Steam ID.
admin /admin quali-close Sort the grid and bake numbered skins.
driver /ac-practice grid-show Print the locked order.
admin /admin race-start Mark the round live and post the join link.
driver /ac-practice race-join Join URL once the race server is up.
admin /admin results-import Finish order in, then results-finalize.

Fixed rules

Not up for vote

  • /ac-practice signup required — the list locks when qualifying closes.
  • Miss quali → back of grid.
  • Quali: server cut detection. Invalid lap, no time.
  • Race: track limits via stewarding, not auto-DQ.
  • Driver aids: your choice in-car.
  • Race length is a time; we set laps per track.
Where we are

The weekend loop above is what we are building toward. First public step is the format vote in #feature-requests. First on-track step is a quiet two-person shakedown — not Round 0. Standings and a live join button land on this same page when a round is actually open.
